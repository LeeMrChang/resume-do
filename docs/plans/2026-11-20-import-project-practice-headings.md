## 根因

用项目 ImportParser + ImportMapper 读取用户 PDF，确认「核心项目经历」「个人项目」「技术实践」均被提取。HEADINGS 缺少对应识别，三者均进入 work 正文；paragraphs 又把「技术实践」与无句末标点的下一行拼接。

## 实施步骤

1. 为三个标题及独立正文归属、顺序与校验补失败测试，运行确认预期失败。
2. 最小补充标题映射：核心项目经历 → project；个人项目 → personal-project（rich）；技术实践 → technical-practice（rich）。已有项目与技能模块不合并、覆盖这些独立模块。
3. 同步导入文档；运行 API 测试，并用原 PDF 再次验证真实解析结果。
4. 浏览器验证导入结果预览、标题、分页与导出；逐行复查本任务差异。保留上一任务未提交改动，不提交、不发布。

真实文件、提取文本、草稿及截图仅放临时目录；回归测试使用虚构内容。
