# 导入未知分区归入待整理内容

## 目标

用户要求保留常用分区，标题无法匹配时，标题及其后内容进入末尾「待整理内容」，直到遇到下一个已识别分区。待整理内容逐行保留，不参与正文断行合并或个人信息字段提取。

## 任务

1. 补充失败测试：未知标题出现在已知分区之后、连续未知标题、恢复已知分区、正文标签不误判、待整理最后及重新打开顺序。
2. 提取阶段保留标题边界信息（PDF 字号/标题样式，DOCX 标题/段落样式）；映射阶段使用常用分区表分类，未知分区切换至待整理，保留原文标题与逐行边界。兼容旧的纯文本入口。
3. 调整默认模块列表与待整理模块，保留已有简历的内容与用户顺序；更新 README/OpenAPI。
4. 运行 API 与前端相关测试、类型检查、构建及浏览器验证；用用户 PDF 验证未知「个人项目」进入末尾待整理，技术实践独立保留；复查差异。

上一轮仅追加标题词表的做法由本方案替代。真实 PDF 与生成产物仅保存临时目录，不提交或发布。
