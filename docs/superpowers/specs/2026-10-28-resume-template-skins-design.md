# 简历模板成品化与 59 套皮肤设计

日期：2026-10-28
状态：补录（需求变更当天实现，非事前批准稿）
需求来源：Notion「模版参考图库」（59 套）与「模版实现评审 · 差距清单与验收标准」（2026-10-28 07:43）

## 目标

1. 把现有 4 套模板从「线框示意图」升级为可交付的成品皮肤：彩色横幅头部、模块标题装饰、日期右对齐、照片位、时间线/侧栏等视觉语言落地。
2. 模板目录覆盖参考图库全部 59 个编号，每套颜色与四项版式（布局 / 头部 / 节标题 / 侧栏）独立配置。
3. 修复产品评审发现的三处缺陷：
   - 分页出现只有模块标题或经历标题的页面。
   - 侧栏内容缺少溢出检测，长邮箱/多行信息被 `overflow: hidden` 静默裁切。
   - 选择模板后 800ms 自动写库，未点「应用」也会保存，取消无法可靠回滚。
4. 模板缩略图与真实渲染同源，避免「弹窗一套皮、预览另一套皮」。

## 非目标

- 不搬运或热链全民简历的 HTML/CSS/图片；59 套均为自研渲染代码与配色。
- 不实现照片裁剪、AI 写作、技能进度条的结构化录入（技能仍为富文本）。
- 不改变模块结构、自动保存、revision 冲突与 PDF 导出任务协议。
- 不把 59 套做成 59 份手写 CSS；使用参数化皮肤类，新增模板只加目录条目。

## 数据与接口

### 模板标识

- 主标识使用参考编号：`1045`、`1015`、…、`1017`，共 59 个。
- 兼容旧数据：`clean → 1045`、`classic → 1033`、`elegant → 1017`、`sidebar → 1030`。
- `packages/schema` 的 `ALL_TEMPLATE_IDS` 同时包含 59 个新 ID 与 4 个旧 ID；Java 白名单一致。
- 新增模板时同步：目录、schema 白名单、Java 白名单、缩略图（自动生成）。

### 模板规格

`packages/templates/src/catalog.ts` 的 `TemplateSpec`：

| 字段 | 说明 |
| --- | --- |
| `layout` | `single` / `timeline` / `sidebar` / `split` |
| `header` | `plain` / `centered` / `photo-left` / `photo-right` / `band` / `band-light` / `block` / `art` / `side` |
| `section` | `rule` / `short` / `bar` / `fill` / `caps` / `ribbon` / `icon` / `pill` / `dots` / `timeline` |
| `accent` / `accent2` / `tint` / `ink` | 模板默认配色；选中模板时写入 `themeColor`，之后仍可自定义 |
| `sidebarTone` / `sidebarBg` / `sidebarInk` | 侧栏与双栏的深浅与配色 |
| `asideSections` | 侧栏承载的模块 ID（技能、荣誉、兴趣；双栏另含教育背景） |
| `photo` | 是否保留照片位；无照片时显示姓名首字，不破版 |

### 内容模型

- `basic.photo` 新增可选字段：`data:image/(png|jpeg|webp);base64,...`，≤ 400,000 字符。
- 照片不计入简历正文字数；API 不做磁盘存储，随简历 JSON 保存。
- PDF worker 仅允许 `data:` / `about:` / `blob:` 资源，照片不会触发外部请求。

### 渲染与分页

- 页面统一输出 `tpl-{id} layout-{kind} hdr-{style} sec-{style}` 类，配色走 CSS 变量。
- 侧栏/双栏：头部与指定模块进入 `aside`，主栏独立测量、独立分页；侧栏内容每页重复。
- 侧栏独立测量高度；预览显示溢出提示，PDF 导出以 `CONTENT_OVERFLOW` 失败，不再静默裁切。
- `keepWithNext` 链总高度超过一页时，整组在新页起始并允许跨页流动，禁止产生只有标题的页面。
- 模板版本与渲染器版本升级到 2；旧队列任务会明确失败，不混用两套渲染。

### 交互

- 模板/字体/颜色/间距弹窗改为草稿态：弹窗内即时预览，点「应用」才写入并触发自动保存；取消、关闭、Esc 丢弃草稿。
- 模板选择器：59 张真实渲染缩略图（A4 缩放）、按风格分组筛选、按名称/编号搜索。

## 验收

沿用需求 §08 与评审口径：

1. 59 套模板均可选中、应用、刷新后保留；旧 4 个 ID 打开不报错。
2. 预览与 PDF 同源；单页、多页、超长内容分页正确，无孤立标题、无静默裁切。
3. 取消模板弹窗后数据库 `appearance` 不变。
4. 侧栏超长内容在预览提示、导出失败并给出可恢复原因。
5. 照片为空显示首字；上传后预览与 PDF 一致。
6. 切换模板不改变模块内容、顺序、显隐状态。

## 风险与限制

- 技能条、兴趣胶囊等结构化视觉仍受 P0 内容模型限制，当前以富文本与列表样式呈现。
- 59 套的一次性浏览器缩略图渲染会增加模板弹窗首次打开开销，需要测量并限制在可接受范围。
- 端到端验证仍需 API、worker、Vite 同版本启动；8080 上的 IDE 调试进程需重启后才会加载新白名单。
- 不做提交、推送或部署，除非用户明确授权。
