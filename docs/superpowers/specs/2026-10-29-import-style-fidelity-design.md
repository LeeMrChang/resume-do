# 导入原样式还原设计（2026-10-29）

> 用户反馈：导入「2026-李昌浩.pdf」后，编辑界面仍是蓝色 1045 模板、照片在右、4 页，而原件是绿色、照片在左、3 页；「期望导入后按原本的样式放在编辑页上」。
> 本文是导入 v2.2（`docs/dev-prompts/2026-10-29-import-v2.2.md`）之后的保真增强。v2.2 §七明确「不做 PDF 像素级版式复刻（L3）」，本设计同样不承诺像素级还原。

## 目标

1. 导入的可编辑简历默认使用贴近原件的版式：主题色取自原件、照片在左、基本信息网格、分区标题色条、时间/单位/角色同行、紧凑行距。
2. 解析不再丢字段、不再把已解析的表头塞进「待整理内容」，PDF 硬换行合并为完整句子。
3. 编辑版页数与原件一致（样例 3 页），导出与预览同源。
4. 原件视图、原件版导出、sha256 不变；仍不上传第三方。

## 非目标

- 不复刻原件的字体文件、图标字体、任意多栏/表格/图形、精确坐标；不读取原件后重排成图片。
- 不改模板选择器其余 59 套皮肤的行为；用户手动切换模板后以用户选择为准。
- 不引入 AI/外部解析服务。

## 方案

### 1. 解析修复（`ImportMapper`）

- 全角空格：表头行先将 U+3000 规范为空格；标签正则使用 `[\s\u3000]*`，使「年　　龄」「籍　　贯」等命中标准字段。
- 待整理：表头字段全部解析成功即整行丢弃；只保留真正未识别的剩余文本。无剩余时不生成「待整理内容」条目。
- 硬换行合并：非项目符号、且上一行未以句末标点（。！？；.!?;:）结束、且当前行不是「技术框架：」「工作内容：」等小标题时，把当前行接到上一段同一 `<p>` 内；项目符号行不合并。
- 分区顺序固定为 教育 → 工作 → 技能 → 项目 → 自我评价（与样例原件一致）；标题优先使用原件中出现的标题文字（如「技能特长」），否则用默认标题。
- 版式默认值：`templateId=imported`、`fontSize=14`、`lineHeight=2.0`、`sectionGap=20`、`pageMargin=32`、`themeColor` 取检测值；检测失败保留旧默认 1045 / 14 / 1.5 / 18 / 42 / #1f5aa6。初版取 13 / 1.47 / 26 / 30，实测第 1 页放入过多技能条目、样例只剩 2 页；按原件行距（约 21.75pt ≈ 28 CSS）和分区间距调整后恢复 3 页且分区归属与原件一致，见[验证记录](../../ops/2026-10-29-import-style-fidelity-verification.md)。

### 2. 源主题色检测（`ImportStyleDetector`）

- PDF：用 PDFBox 渲染第 1 页（96 dpi，上限 1200px），按 4 bit 量化统计「饱和且非黑白」颜色；颜色需在 32×32 网格中覆盖足够多格子，按 `count × cells` 取最高分。样例 `#67a886` 得分 1619×32，肤色最高仅 1017×9，可区分照片。
- DOCX：优先读 `word/theme/theme1.xml` 的 `accent1`（`srgbClr`/`sysClr lastClr`）；否则统计 `word/styles.xml` 中最常见的非灰 `w:color`（至少出现 3 次）。
- 任一步失败返回 `null`，导入不阻断。只读取本地文件，不联网。

### 3. 新模板 `imported`（原样还原）

- `header: classic`：照片在左 110×141，姓名大字使用主题色，联系方式为 2 列网格（年龄/性别/籍贯/工作年限/电话/邮箱 + 其余字段），带图标与标签。
- `section: classic`：浅色底条 + 左侧主题色竖条 + 主题色标题。
- 记录头 `recordInline`：`时间 | 单位 | 角色` 单行，日期使用 `2024-03 ~ 2026-03` 格式；角色不再单独占行。
- 隐藏页脚页码（原始 PDF 无页码），页高不预留页脚空间。
- 正文段落使用紧凑间距（段落/项目符号不再额外 5px），项目正文左缩进 24px。

### 4. 数据与接口

- `TEMPLATE_IDS` 增加 `imported`；后端 `ResumeValidator` 白名单同步。
- 不新增接口、不改数据库结构；`appearance` 已随简历持久化。
- 权限与安全不变：单用户单账本、原件本地保存、导入并发限制 Semaphore(2)、文件类型/大小校验沿用。

## 验收

1. 用真实样例 PDF 在测试账号导入：姓名/年龄/性别/籍贯/工作年限/电话/邮箱/出生年月等落入标准字段；自定义键值对只剩真正未知字段；待整理为空。
2. 预览显示 3 页；主题色接近 `#67a886`；照片在左；分区标题为绿色条；教育/工作记录单行显示时间-单位-角色。
3. 项目正文中跨行断句合并为完整句子。
4. 编辑版导出 3 页；原件版导出的 sha256 与上传文件一致。
5. 用户从不改模板时刷新页面仍保持 imported 样式；手动切换模板后正常。

## 风险

- 主题色检测对大面积纯色照片可能误判：用网格覆盖度与饱和度过滤降低概率；失败时回退旧模板。它是启发式，不保证与原件一致。
- 紧凑版式对不同内容的页数不保证与原文件一致；验收以样例与现有回归用例为准。
- 合并断行依赖「上一行无句末标点」的启发式，可能把作者有意分行的短句合并；内容不丢失，可在编辑器内改回。
