# 2026-10-30 简历编辑器模块扩展设计

## 目标

把编辑页模块栏与模块正文对齐参考稿：每个模块都能显示/隐藏、左右调整顺序、重命名；补齐「报考信息」模块；支持用户新增自定义模块、删除不需要的置灰模块；模块正文改为四列灰底字段、左侧列表卡片式布局；Tab 行在内容区内居中且不溢出。

## 非目标

- 不实现参考稿中的 AI 生成 / 整份简历优化 / 技能推荐标签：当前没有整份生成能力，按钮不做占位。AI 润色与精炼在后续追加中接入，见文末「追加」。
- 不改导入解析的标题识别（导入仍落到原有模块，未知标题继续进「自定义模块」）。如需识别「报考信息 / 实习经验 / 校园经历 / 荣誉证书 / 兴趣爱好」，另行改 `ImportMapper`。
- 不做模块内条目的拖拽排序，保留现有序号按钮。

## 数据与兼容

- schema 默认模块顺序调整为：报考信息（新增，`application`，rich，默认隐藏）→ 教育背景 → 工作经验 → 专业技能 → 项目经验 → 实习经验 → 校园经历 → 荣誉证书 → 自我评价 → 兴趣爱好 → 自定义模块。
- `application` 只作为默认模块加入，不新增后端字段；模板渲染按 `type` 通用处理，任意合法 id 都会渲染，无需改 59 套模板与分页。
- 打开旧简历时补齐缺失的默认模块（隐藏、空内容）：只在编辑器内存中补齐，用户未编辑则不写库；首次编辑后随自动保存写入。补齐时按默认顺序插入到相邻默认模块前，未知模块（如 `custom-2`）保持原位置。
- 补齐只执行一次：文档写入 `moduleDefaultsApplied: true` 标记后不再补齐，用户删除的内置模块不会在下次打开时被重新加回。默认文档与后端 `empty-resume.json` 直接带该标记；没有标记的旧文档先补齐再标记。
- 已存在的简历保持原有模块顺序，不重排；隐藏模块不参与渲染与导出。

## 交互

- 模块栏：基本信息、求职意向为固定模块（无开关/箭头）；其后按文档顺序列出全部模块。
  - 每个模块上方：左移箭头、绿色开关（关闭时置灰且模块名变浅）、右移箭头；箭头在悬停、聚焦或选中时显示。
  - 模块名右侧铅笔：就地输入重命名，回车或失焦保存，Esc 取消，空名回退并提示；长度沿用 schema 的 1–20 字。
  - 已隐藏（置灰）的模块在悬停、聚焦或选中时显示红色减号「⊖」：点击弹出二次确认，确认后从文档中删除该模块及其内容；可见模块不显示减号，需先关闭开关再删除。删除后 Tab 行重新居中。
  - 行末圆形「＋」：新增 `custom-N`（rich，默认显示，标题「自定义模块」，自动选中）。
- 基本信息、求职意向正文顶部显示参考稿的提示条（橙色信息图标）：
  - 基本信息：填写的信息会自动排版在简历上，不需要的信息可以选择不填或删除内容。
  - 求职意向：参考稿的提示描述的是可开关模块的通用操作，本项目求职意向固定显示且不可隐藏，因此改为说明实际行为：求职意向会显示在简历顶部，全部字段均可留空。
- 正文版式：字段四列（窄屏两列/一列）、灰底无边输入框；记录类模块左侧为列表卡片（标题 + 副标题、选中态白底绿框），底部绿色胶囊「＋ 新增…」；右侧为字段行 + 正文编辑器。
- Tab 行与正文共用同一居中容器（`max-width` + `margin: auto`），模块多时按可用宽度收缩、标题省略，不出现横向溢出。

## 验收

- 默认简历显示 11 个模块 + 基本信息、求职意向；隐藏模块名置灰，开关可切换并自动保存。
- 重命名、左右移、添加自定义模块、删除置灰模块均可保存并在刷新后保留；删除内置模块后不再因补齐逻辑重新出现。
- 关闭模块后预览与编辑版导出不含该模块；打开模块且有内容后正常渲染。
- 1440 / 1100 / 900 宽度下 Tab 行居中、无横向滚动；自定义模块较多时标题省略显示；删除模块后仍居中。
- 旧简历打开不丢失内容、不自动产生 revision；首次编辑后才写入补齐的默认模块。

## 风险

- 补齐默认模块会让首次编辑的 PATCH 体积略增（空模块），不影响渲染。
- 旧简历模块顺序与默认顺序可能不同（如自我评价在实习经验之前），保持原顺序，不自动重排。
- 删除模块不可撤销，且当前没有模块库可恢复已删除的内置模块；二次确认文案已说明内容一并移除。只对置灰模块显示减号以降低误删风险。
- 参考稿的拖拽排序、AI 能力未实现，验收时单独说明。

## 追加：AI 润色与精炼（2026-10-30，补录）

后端先提供了 `POST /api/ai/rewrite`（见 [AI 润色与精炼接口](../../api/ai-rewrite.md)），本次在正文编辑器下方接入两个按钮：

- 「AI 润色」为 `polish`，「精炼内容」为 `condense`；不提供 AI 生成或整份简历优化。
- 发送前弹出同意框，展示将发送的纯文本正文、意向职位与字数；复选框默认不勾选，同意后才发送 `privacyConsent: true`。不发送基本信息、照片或完整文档。
- 富文本转为保留换行的纯文本发送；结果显示原文、建议与 warnings，用户可取消、重新生成或采用。
- 发起时记录正文快照；采用前若正文已变化，二次确认后才覆盖。切换模块、条目或简历会卸载面板并取消旧请求。
- 采用后通过现有 `onChange` 进入自动保存；AI 接口本身不写简历。
- 前端超时 40 秒；`AI_REQUEST_PENDING`／超时／网络错误重试沿用同一 requestId（不自动另发付费请求），其他失败生成新 ID。
- 默认关闭；服务端未启用或缺密钥时显示后端中文错误，不产生模型调用。
