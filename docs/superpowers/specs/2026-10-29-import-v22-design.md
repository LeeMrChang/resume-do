# 简历导入 v2.2 设计

## 范围与决定

默认导入本地提取 PDF/DOCX 内容，直接创建可编辑简历；不经过校对表单，不调用外部 AI。原件字节永久关联到该简历，直到删除。

一个逻辑简历占一行 `resumes`：`kind=structured`，同时保存 `document/appearance` 与 `source_*`。顶栏将有原件的同一行展示为可编辑/原件两个视图选项，两态共享 ID、额度和删除生命周期。保留旧 `kind=original` 数据兼容，不自动修改已有账号的数据。旧原件仅在用户显式点击“返回编辑器”时，在原 ID 上解析并生成编辑内容，保留关联原件且不新增额度。

`POST /api/imports/direct` 完成校验、提取、映射、照片提取与持久化。原有确认接口同样保留原件。复用 V3 的 source 列，无需新增迁移或新任务队列。PDF 原件预览逐页按实际尺寸缩放；Word 原件提供下载，不伪造 PDF。

导出弹窗先选版本：有 PDF 原件时默认原件版，直接下载 source，不进渲染队列；编辑版走已有 ExportService。Word 原文件不能冒充 PDF，仅编辑版支持 PDF 导出。

## 数据正确性

提取成功的日期/机构/岗位行只写结构化字段，不重复塞入正文。未知段落保留到待整理，禁止猜测缺失的出生年月、民族等信息。年龄可由出生年月按当前月份计算；仅有原文年龄时保留原文年龄。照片从本地内嵌图提取，失败不阻断正文；显示开关默认开，关闭时两端渲染均不输出图片或占位。

新增可选基本字段及自定义键值，旧文档兼容。文件沿用临时写入、事务回滚补偿、原子 rename、孤立文件清理机制。删除一行即同时删除两态，保留明确的关系确认文案。

## 验证安排

用户最新明确要求“你不用测试，我来测”，本轮不执行单元、集成或浏览器验收，不声称验收已通过。仅进行必要的编译/类型静态检查。真实文件验收及照片、解析内容、分页效果由用户执行。
