# 简历导入 P0 设计

需求源：2026-10-29 通过桌面 Notion 阅读《简历导入 · 需求说明 v1.0》，页面 `407a36e1ae8a81779261d721e53b0853`。独立需求页明确将导入列为 P0，本地实现以此为准；未修改 Notion。

## 1. 范围决策

- IMP-D1：仅服务端本地解析，无外部 AI、OCR、内容润色或版式复刻。PDF 使用 Apache PDFBox 3.0.8；DOCX 使用 JDK ZIP + 禁用 DTD／外部实体的 StAX 读取正文、表格及附属文字，不渲染上传 HTML、不访问外部关系。
- IMP-D2：单文件 20 MiB；额外资源边界：PDF 100 页，DOCX 解压总计 50 MiB、单项 10 MiB、512 项；源文字最多 100000 字，超限明确失败，保留原文件，不截断冒充成功。
- IMP-D3：原文件及草稿最长 24 小时；确认／放弃后清理原文件。API 每分钟清理，到期即禁止访问。删除失败保留重试。临时目录仅供 API 使用，不需要 PDF worker 解析。
- IMP-D4：仅 .pdf / .docx；.doc 提示另存，密码保护、损坏、伪扩展名、宏、嵌入对象、XML 外部实体明确拒绝。

## 2. 接口和持久化

新增 Flyway V2 `import_jobs`，不修改 V1、不复用导出表。保存 owner、随机 public_id、原文件名／内部文件键、状态、原文、校对草稿、版本、错误、到期时间、确认后的 resume public_id。

| 接口 | 行为 |
| --- | --- |
| POST /api/imports multipart file | 保存临时文件，创建异步解析任务，202；不创建简历 |
| GET /api/imports | 当前用户尚未确认且未过期任务，供刷新恢复 |
| GET /api/imports/{id} | 状态、原文、草稿、错误；所有操作均按 owner 校验 |
| GET /api/imports/{id}/file | 私有附件下载原文件，no-store；不能访问他人文件 |
| PATCH /api/imports/{id} | 按版本保存校对草稿，不写 resumes |
| POST /api/imports/{id}/retry | 原文件重试；用户编辑过的草稿不被自动覆盖 |
| POST /api/imports/{id}/confirm | 行锁 + 事务内复用 ResumeService.create，始终新建；同任务确认幂等返回原新简历 |
| DELETE /api/imports/{id} | 放弃临时任务，不影响已有简历 |

解析执行器并发和队列有上限；30 秒超时标记失败，迟到结果不覆盖新状态，原文件留供下载、重试／人工整理。重启时遗留 processing 任务转失败恢复。校对草稿版本检查避免迟到请求覆盖。确认前必须保存草稿，客户端确认失败可安全重试。

## 3. 内容与 UI

登录后顶栏提供“导入简历”和简历切换。确认前先保存当前编辑内容，不能覆盖当前简历。上传支持点击／拖拽，清楚列出格式、大小、隐私与保留规则；进度使用上传／解析状态，不伪造百分比。校对左栏为提取原文及原文件下载，右栏为普通可编辑字段、记录和模块归属。允许增加／删除条目、修正日期、将待整理内容移动到既有模块。退出校对可保留草稿或明确放弃。

章节别名识别基本信息、求职意向、教育、工作、项目、技能、评价；仅提取有明确依据的字段。每条原文保留在对应正文或待整理桶；多条日期经历按原顺序切分，不补猜学历、单位或日期。超长富文本分为多条自定义记录，仍遵守现有 schema 上限；无法保存的内容显示校验错误并保留草稿／原文件。

## 4. 验收追踪

| 条目 | 落点 | 验证 |
| --- | --- | --- |
| IMP-01/02 | ImportController、ImportParser、multipart/Nginx 限额 | 文件魔数、大小、损坏／保护／扫描件／ZIP 边界测试 |
| IMP-03/04 | ImportMapper | 多经历／日期／顺序／未识别原文保留测试 |
| IMP-05 | ImportDialog、ImportService 草稿接口 | 保存草稿、刷新恢复、归属调整、取消不建简历 |
| IMP-06 | confirm 事务与 ResumeService.create | 重复确认幂等、不同任务分别新建、旧简历不更新 |
| IMP-07/08 | 编辑器选择新简历与原有保存／导出 | 导入字段、模块排序显隐、保存重载与 PDF 验收 |

七条验收分别对应：完整上传至导出链路；逐字段和逐经历编辑；失败保留源文件／已识别草稿；确认内容刷新仍在；导出完整内容及隐藏规则；无外部 AI 并展示隐私说明；全程不更新旧简历。单元测试通过不等于浏览器、MySQL、Docker、实际 PDF 下载验收通过，记录实际结果。
