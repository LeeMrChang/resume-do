# 同机云部署与 CI/CD 实施计划

依据：[设计](../specs/2026-10-30-cloud-cicd-design.md)。

1. 先写打包安全、端口隔离与发布失败路径测试，实际运行失败，再实现。
2. 新增云端 Compose、无密钥配置示例、worker 健康检查、原子发布/备份/初始化脚本。
3. 新增只打包明确白名单文件和镜像的发布工具，防止私密配置或数据混入归档。
4. 新增 GitHub CI/CD、SSH 接入脚本、操作手册；修正 Docker 构建上下文中的秘密排除规则。
5. 执行部署脚本测试、Shell 语法、TS/Java 与可运行的检查；记录 Docker/网络限制。
6. 服务器资源核实后初始化配置，配置 GitHub Secrets，推送启用流水线并用 SSH 隧道验收。需要用户在正常终端接入时给出一条明确命令，不声称远端已完成。

本轮不迁移开发机真实简历、不改 cost，不开放公网入口。
