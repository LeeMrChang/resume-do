# 简历导入 v2.2 实施计划

1. 扩展已存在的 source 存储能力，允许 structured 简历关联 PDF/DOCX；默认新入口直接解析并创建，原确认路径保留源文件。
2. 修复经历头重复正文、基本信息多列、求职意向提取，增加可选字段与本地照片提取。
3. 扩展 schema、Java 校验、基本信息表单及共享模板，支持照片开关和年龄。
4. 顶栏成对视图、同 ID 双向返回与刷新恢复，导出原件/编辑版分支，关系删除提示。
5. 更新文档和交付限制。按用户最新指示，不执行测试；编译检查与功能验收分开记录。

验收由用户操作：真实三页 PDF 直接进入编辑器、章节无重复；原件三页及 sha256 一致；照片开关影响预览和编辑版导出；缺失字段不编造；刷新及双向切换保留修改；删除两态同时消失。扫描件无 OCR 不生成伪造的完整可编辑内容。
