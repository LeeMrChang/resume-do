接入项目需要做什么

单栏版式可以扩展现有 packages/templates；双栏、侧栏及带照片的模板需要补充分区规则、版心测量和分页逻辑。

新增可编辑模板时，需要同步更新 TypeScript 的 templateId 校验、Java 的模板白名单、模板选择器及预览缩略图，并使用同一套渲染代码验证实际 PDF。不能只增加图片或前端选项。

本目录仅保存公开展示的预览图片与来源索引，不包含用户简历正文，也没有修改原站简历。目录清单：catalog.json。
