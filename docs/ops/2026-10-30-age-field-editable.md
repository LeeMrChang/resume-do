# 2026-10-30 年龄字段可编辑验证记录

需求：用户反馈基本信息里的「年龄（自动计算）」无法输入，且不希望简历直接展示年龄。经确认采用最小范围方案——**年龄字段可编辑、可清空**；未新增「展示年龄」开关，也未移除字段。

## 行为

| 出生年月 | 年龄输入框 | 展示 |
| --- | --- | --- |
| 空 | 可编辑，可直接填写任意文本（≤30 字） | 有值则在预览与导出中展示，留空则不输出「年龄」一行 |
| 已填 | 只读，按当前月份自动计算 | 始终按计算结果展示，`basic.age` 保留但不参与渲染 |

清空年龄不会清除出生年月；重新填入出生年月后年龄回到自动计算。导入解析逻辑未改，原文年龄仍写入 `basic.age`，只在没有出生年月时才展示。

## 实现

| 位置 | 改动 |
| --- | --- |
| `apps/web/src/EditorPage.tsx` | `Field` 增加可选 `readOnly`、`onChange` 改为可选；年龄按 `birthMonth` 分支渲染：有值走只读自动计算，无值走可编辑 `basic.age`；补充说明文字 |
| `apps/web/src/styles.css` | 新增 `input[readonly]`（`--canvas-inset` 底、`--fg-muted` 字、默认光标），只读态与普通输入有可见区分 |
| `apps/web/tests/editor.e2e.ts` | 新增断言：无出生年月可编辑并保存、清空后预览不再出现「年龄」、填出生年月后变为只读且展示计算值 |
| `README.MD` §7.5 | 同步年龄的编辑与展示规则 |

模板无需改动：`packages/templates/src/blocks.ts` 原本就会过滤空值，清空后年龄行自然消失。
